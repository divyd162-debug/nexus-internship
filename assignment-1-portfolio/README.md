| Requirement | Implementation Detail |
|---|---|

## How to View Locally

1. Clone or download the repository.
2. Navigate to `assignment-1-portfolio/`:
   ```bash
   cd assignment-1-portfolio
   ```
3. Open `index.html` in any web browser, or serve it using Python's built-in HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.
