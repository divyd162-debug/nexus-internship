# Nexus Internship - Web Development

This repository contains all assignments, practice exercises, and projects completed during the Nexus Internship Web Development program.

## Repository Contents

### 1. [Assignment 1: Portfolio Webpage](assignment-1-portfolio/)
- **Focus:** HTML5 & CSS3 Structure + Design + Layout
- **Sections:** About, Education, Skills, Projects, Contact, Footer
- **Features:** Semantic HTML elements, modern CSS variables, responsive layout (Flexbox & CSS Grid), profile card with image, contact form.

### 2. [Week 1: HTML Basics Practice](week-1-html-basics/)
- **Focus:** HTML Page Structure, Tags, Elements, Attributes, Lists, Tables, Forms, Multi-Page Navigation
- **Page 1 (`index.html`):** Heading hierarchy, paragraph formatting, responsive image, lists, and semantic tags.
- **Page 2 (`table.html`):** Student records table with student names, roll numbers, marks, totals, percentages, and footer summary.
- **Page 3 (`form.html`):** Complete student registration form with text/email/tel/date inputs, select dropdowns, radio/checkbox controls, and submit/reset buttons.
- **Navigation:** Persistent navigation header across all 3 pages allowing seamless movement.
