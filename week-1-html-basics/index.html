HTML Page Structure, Heading, Paragraph & Image

Demonstrating foundational HTML elements: document tree, typography hierarchies, semantic tags, attributes, and multi-page site navigation.

📖 1. HTML Headings and Paragraph Structure

HyperText Markup Language (HTML) forms the backbone of any web application. A well-structured webpage utilizes semantic elements such as <header>, <nav>, <main>, <section>, and <footer> to convey meaning to browsers, screen readers, and search engine indexers.


Headings range from <h1> (the highest conceptual rank) through <h6>. Paragraphs defined by <p> group cohesive blocks of text, separating thoughts cleanly with predictable vertical margins.

🎯 2. Covered HTML Fundamentals

Tags vs. Elements vs. Attributes

A tag is the syntax bracket (e.g. <p>), an element comprises opening tag, content, and closing tag, while attributes provide extra configuration (e.g. id, class, src, href).

  • Element syntax: <tag attr="val">Content</tag>
  • Self-closing tags: <img>, <input>, <br>

Lists & Organization

HTML offers both ordered and unordered sequences for grouping related items cleanly.

  1. Unordered lists with <ul> and <li>
  2. Ordered numbered lists with <ol>
  3. Description lists with <dl>, <dt>, <dd>

Hyperlinks & Multi-Page Navigation

Using anchor tags <a href="..."> allows seamless routing across internal pages, document sections, and external web resources.

  • Internal page jumps via element IDs
  • Relative path navigation between local HTML files
  • External links with target="_blank"
